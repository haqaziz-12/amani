LOGO INSTRUCTIONS
=================

Current placeholder: logo.svg (brand-colored geometric mark)

To use your real logo:
1. Upload your logo file as public/logo.jpg (or logo.png)
2. Then update the Image src references in:
   - src/components/layout/Header.tsx
   - src/components/layout/Footer.tsx
   - src/app/page.tsx
   - src/app/about/page.tsx
   - src/app/products/page.tsx
   - src/app/products/[slug]/page.tsx

Or keep logo.svg and replace its content with a more accurate SVG of your real logo.

Later the Admin panel will allow uploading a new logo via Supabase Storage without code changes.
